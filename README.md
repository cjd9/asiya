# 🏥 Online Physiotherapy Management System

An **online physiotherapy management system** built with **PHP (CodeIgniter Framework)** to streamline clinic operations and enhance patient care. The system allows physiotherapists and clinic staff to manage treatments, exercises, reminders, and appointments efficiently in a centralized platform.

---

## ✨ Features

- **Patient Management**
  - Add, update, and view patient profiles.
  - Track medical history and progress notes.

- **Treatment Records**
  - Record prescribed treatments and therapies.
  - Maintain detailed session logs.

- **Exercise Management**
  - Assign tailored exercise plans to patients.
  - Upload instructions, videos, or documents.

- **Appointment Scheduling**
  - Book, update, or cancel appointments.
  - View calendar with daily/weekly/monthly schedule.

- **Reminders & Notifications**
  - Automated reminders for appointments and exercises.
  - Custom notifications for treatment follow-ups.

- **User Roles & Permissions**
  - Admin, physiotherapist, staff, and patient access levels.

---

## 🛠️ Tech Stack

- **Backend:** PHP (CodeIgniter Framework)
- **Frontend:** HTML5, CSS3, Bootstrap, JavaScript/jQuery
- **Database:** MySQL
- **Other Tools:** Composer, PHPMailer (for email reminders)
